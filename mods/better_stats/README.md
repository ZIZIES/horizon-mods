# Statistics Search for Horizon

The part of TheCSDev's Better Statistics Screen that fits Horizon's own
Statistics screen, written from what that mod does (its code is all rights
reserved and was not read). A search box in the footer, left of Done: click
it, type, and the Items and Mobs tabs keep only the rows whose name or id
holds every word. Escape clears the text, then lets go of the box; a right
click on the box clears it.

Not here: the rest of Better Statistics Screen (the item grid, mob models,
filters for empty stats, the General tab's search). Those need the screen
redrawn, which a native mod cannot do at this Horizon revision. While a
search leaves a tab empty, that tab greys out like any empty tab.

Status: attempted. Compiles into the game; not played yet.
